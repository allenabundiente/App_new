# HulogTrack — Brand Assets Checklist

This folder is the single home for every icon, logo, and store graphic the
app needs. The current set was generated by
[`tools/generate-branding.mjs`](../tools/generate-branding.mjs) — **edit the
SVG master (or the glyph/color constants in the generator), then run:**

```bash
node tools/generate-branding.mjs
```

…and every PNG rebuilds automatically at every size.

## ✅ What to add / keep — and the exact format

| Asset | Size (px) | Format | Used for |
|---|---|---|---|
| `logo.svg` | vector | **SVG** | Master, web, docs, print |
| `app-icon-1024.png` | 1024×1024 | **PNG, RGBA, square, no transparency issues** | Apple App Store icon; also iOS app icon (Xcode accepts a single 1024) |
| `app-icon-512.png` | 512×512 | **PNG** | Google Play Store listing icon |
| `app-icon-192.png` | 192×192 | **PNG** | PWA / web manifest |
| `app-icon-96.png` | 96×96 | **PNG** | small Android/web |
| `app-icon-48.png` | 48×48 | **PNG** | favicon-grade web icon |
| `favicon.ico` | 32×32 (ICO container) | **ICO** (holds PNG) | browser tab favicon |
| `notification-icon.png` | 96×96 | **PNG, WHITE silhouette on transparent** | Android status-bar notification icon (the OS tints it, so it must be a solid white shape) |
| screenshots | 1290×2796 (iPhone 6.7″), 1080×2400 (Android) | **PNG or JPG** | App Store / Play Store listing (min 2, recommend 6–8) |

**Format rules of thumb**
- **App/launcher icons → PNG** (universal, lossless). Never JPG (no
  transparency, edge artifacts).
- **Vector master → SVG.** Keep one SVG as the source of truth; rasterize
  from it (the generator does this for you).
- **Favicon → ICO** for maximum browser support (or keep PNG for modern
  browsers only).
- **Android adaptive icons → PNG foregrounds + a `values/ic_launcher.xml`**
  (see below) — never hand-crop your full-bleed icon into the mipmap folders.

## 🗺 Where each file goes in a React Native project

When you generate the native folders (`npx react-native prebuild`, or the
`ios/` + `android/` folders appear), copy:

**Android**
```
android/app/src/main/res/
├── mipmap-mdpi/    ic_launcher.png   (48×48)
├── mipmap-hdpi/    ic_launcher.png   (72×72)
├── mipmap-xhdpi/   ic_launcher.png   (96×96)
├── mipmap-xxhdpi/  ic_launcher.png   (144×144)
├── mipmap-xxxhdpi/ ic_launcher.png   (192×192)
└── mipmap-anydpi-v26/
    ├── ic_launcher.xml              (adaptive icon: <background> + <foreground>)
    └── ic_launcher_round.xml
```
Adaptive icon best practice (API 26+):
- **foreground**: 432×432 PNG with the artwork inside the central 66%
  (a ~108dp safe circle) — outside that is cropped by launchers.
- **background**: a solid color PNG or color resource.
Then point `AndroidManifest.xml` at `@mipmap/ic_launcher` as usual.

**iOS**
```
ios/<App>/Images.xcassets/AppIcon.appiconset/
└── Contents.json
```
Modern Xcode uses **one** 1024×1024 PNG (`app-icon-1024.png`) — set it in
`Contents.json` under `"platform": "ios", "size": "1024x1024"`. Older
setups need the full 1x/2x/3x ladder (20/29/40/58/60/76/80/87/120/152/167/180).

**Web (if you host a dashboard)**
```
public/ → favicon.ico, app-icon-192.png, app-icon-512.png
manifest.json → icons: [{src:'/app-icon-192.png', sizes:'192x192', type:'image/png'}, ...]
```

**Expo / app.json shortcut** (if you ever switch to Expo):
```json
{
  "icon": "./assets/branding/icons/app-icon-1024.png",
  "splash": { "image": "./assets/branding/logo/logo.svg", "resizeMode": "contain" },
  "android": { "adaptiveIcon": { "foregroundImage": "./assets/branding/icons/app-icon-512.png" } }
}
```

## 🎨 Design tokens (keep consistent)

- Background gradient: `#6d5ef2` → `#2b1f8c` (violet, deep navy)
- Mark: white **HT** monogram
- Accent: success green `#22c55e` (the payment/settlement dot)
- Radius: ≈22% of canvas
- The app's dark UI theme uses the same violet (`#6d5ef2`) on `#0a0e1a`

## 📸 Store screenshots checklist

1. **Portrait** 6.7″: 1290×2796 (iOS) / 1080×2400 (Android).
2. Cover the three portals in order: Buyer (balance), Seller (record a
   payment), Admin (verification queue).
3. Use the dark navy UI as-is — no light-mode mockups.
4. Keep the top ~200px and bottom ~180px clear of critical UI (store
   UIs overlay chrome there).
